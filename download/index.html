05 · Download

Download Overstay

Free and open source. There is no public release yet. A first tester beta comes after the code has compiled in CI on macOS and real Macs have tried it. The changelog and its RSS feed will say when it is out.

Open GitHub Releases View source

macOS 13 or later · Apple silicon and Intel · MIT licence

  1. Download from ReleasesTake the latest build from GitHub Releases and compare its checksum with the one in the release notes: shasum -a 256 <file>. Use no other site.
  2. Move Overstay to ApplicationsOpen the download and drag Overstay into the Applications folder.
  3. Open it the first timePublic builds are unsigned betas until there is a Developer ID, so macOS blocks the first launch. On macOS 13 and 14, right-click Overstay, choose Open, then Open again. On macOS 15 or later, open it once, then go to System Settings › Privacy & Security and choose Open Anyway.

Or build it yourself

Everything is in the repository. You need a Mac with Xcode and XcodeGen; the steps are in the README.

Overstay asks for no permissions, makes no network connections and is not affiliated with or endorsed by any of the tools it detects. A stopped process cannot be brought back; read what it reads and what it never does first.

Only from github.com/EverydayOpen/overstay/releases. Overstay is free: anyone asking you to pay for it is not us.
