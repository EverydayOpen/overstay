# Overstay v1 build plan (the contract)

Overstay is a free, open-source, offline macOS app (EverydayOpen's third, after Whydunit and Tirekick) that finds the
processes AI coding agents left running with nothing attached to them, shows how much memory they hold and which project
started them, and stops them safely. The product decision, hook, launch plan and kill tests are in the Whydunit repo's
`docs/next/APP3.md` (quoted below only where code depends on it). This file is the build contract for parallel owners
(§10). Where it disagrees with APP3.md, this file wins; propose changes in your report instead of diverging.

**What has run:** `OverstayCore/Model` (the frozen types) and one placeholder test suite build and pass on Linux in
Docker (`bash tools/test_core_docker.sh`, 2026-10-02, no warnings). `tools/safety_greps.sh` passes on that tree and
was checked against injected violations. Nothing else exists yet. There is no Xcode on the dev machine, so every
Mac and App file is "written, not compiled" until a `macos-26` CI run says otherwise, and nothing about runtime
behaviour on a real Mac is claimed (AGENTS.md).

## 2. What the system gives us (all public or long-standing; VERIFY each on macOS 13, 15 and 26)

Header-level facts come from `libproc.h`, `sys/proc_info.h`, `sys/sysctl.h`, `sys/resource.h` in Apple's open-source
XNU (opensource.apple.com / github.com/apple-oss-distributions/xnu). Swift imports them through `Darwin`. Anything not
checked against a header is marked VERIFY. Owner: mac.

| Need | Call | Notes |
|---|---|---|
| List pids | `proc_listpids(UInt32(PROC_ALL_PIDS), 0, nil, 0)` returns the byte size; allocate with headroom (+20%), call again with a buffer; result is bytes, divide by `MemoryLayout<pid_t>.size`; drop zeros. | `PROC_ALL_PIDS` imports as `Int32`, the function wants `UInt32`. No permission. |
| ppid, pgid, uid, start time, status, flags, tty | `proc_pidinfo(pid, PROC_PIDTBSDINFO, 0, &info, Int32(MemoryLayout<proc_bsdinfo>.size))` must return the struct size. | `pbi_ppid`, `pbi_pgid`, `pbi_uid`, `pbi_start_tvsec`, `pbi_start_tvusec`, `pbi_status` (`SZOMB` = 5: skip zombies), `pbi_flags`, `e_tdev`, `pbi_comm`, `pbi_name`. Works for other users' processes too (used only for ancestry). VERIFY `e_tdev` when there is no tty (`NODEV` is all ones; also treat 0 as none) and `PROC_FLAG_CONTROLT` / `PROC_FLAG_SLEADER` values; if unsure use `e_tdev` and `getsid`. |
| Session | `getsid(pid)` | -1 on failure. `isSessionLeader = (sid == pid)`. |
| Executable path | `proc_pidpath(pid, &buf, 4096)` | `PROC_PIDPATHINFO_MAXSIZE` is a computed macro and may not import: use 4096. Returns 0 when unreadable. |
| cwd | `proc_pidinfo(pid, PROC_PIDVNODEPATHINFO, 0, &vnodeInfo, size)`, then `pvi_cdir.vip_path` | A fixed `char[1024]` that Swift imports as a tuple: read it with `withUnsafePointer(to: &…vip_path) { $0.withMemoryRebound(to: CChar.self, capacity: 1024) { String(cString: $0) } }`. Same-uid only. |
| argv and env | `sysctl([CTL_KERN, KERN_PROCARGS2, pid])` into a buffer of `KERN_ARGMAX` bytes | Layout: `Int32 argc`, the exec path, NULs, then `argc` argv strings, then `KEY=value` env strings. Same-uid ordinary processes work; hardened/SIP processes refuse (count them in `unreadableCount`). Env is read in memory against an allow-list of keys and only the **names** present are kept (§5.2). VERIFY the layout and `KERN_ARGMAX` on 13/15/26. |
| Memory | `proc_pid_rusage(pid, RUSAGE_INFO_V4, ptr)` then `ri_phys_footprint` | The measure Activity Monitor labels "Memory". The out-parameter is `rusage_info_t *`: bind a `rusage_info_v4` with `withMemoryRebound(to: rusage_info_t?.self, capacity: 1)`. `RUSAGE_INFO_V4` imports as `Int32`. VERIFY. |
| Own identity | `getpid()`, `getuid()`, `getppid()` | |
| Signal | `kill(pid, SIGTERM)` and `kill(pid, SIGKILL)` | Positive pid greater than 1 only. `errno` ESRCH = already gone, EPERM = refused. |
| Project root | `FileManager.default.fileExists(atPath: dir + "/.git")` walking up from cwd | `.git` is a directory, or a file in a worktree: either counts. stat only, never opened. |
| UI | `MenuBarExtra` + `.menuBarExtraStyle(.window)`, `Window`, `NavigationSplitView`, `ImageRenderer` (all macOS 13) | §11. |

## 3. Safety rules (review + CI; all hard)

The product signals processes. A bug here can stop the wrong thing, so these are rules, not guidelines.

1. **One signal file.** `kill(`, `killpg(`, `pthread_kill(`, `raise(` and every `SIG*` name appear only in
   `Sources/OverstayMac/Signal.swift`. The only signals ever sent are SIGTERM and SIGKILL, and the pid argument is
   always a validated positive integer greater than 1: no `kill(0, …)`, no negative pids, no process groups.
2. **No shell, no child processes.** `Process`, `NSTask`, `/bin/sh`, `exec*`, `posix_spawn`, `system`, `popen`,
   `fork`, AppleScript, `ps`, `pkill`, `killall`, `lsof`, `launchctl` and `NSRunningApplication` appear nowhere in
   `Sources/` or `App/`. (Tests may use them; the Mac tests start fixtures through `Process`.)
3. **Processes only.** Overstay never deletes, trashes, moves, copies or renames a file, never changes permissions
   or attributes, never touches iCloud/FileProvider/CloudKit.
4. **Who can be signalled.** Same uid as the user; pid greater than 1; not our own pid; not any ancestor of our own pid
   (the shell, terminal or IDE hosting us); not a zombie; never a process whose uid changed.
5. **Protected list** (hard-coded in Core, `Protected.swift`, not user-removable): `launchd`, `kernel_task`,
   `WindowServer`, `loginwindow`, `Finder`, `Dock` and anything under `/System/`, `/usr/libexec/`, `/usr/sbin/`,
   `/sbin/`, `/Library/Apple/`; anything inside a `.app` bundle other than a signature-matched automation browser;
   Terminal, iTerm, Ghostty, WezTerm, Kitty, Alacritty; tmux, screen, zellij; ssh, sshd, ssh-agent, gpg-agent; Docker,
   Colima, Lima, OrbStack and VM helpers (qemu, vz); databases (postgres, mysqld, mongod, redis-server, sqlite
   servers) and language servers (sourcekit-lsp, clangd, gopls, rust-analyzer, pyright, tsserver and `*-language-server`);
   any agent-root process (a live session); any process with a controlling tty whose session leader is still alive;
   Overstay itself. The user's "never touch this" list (`Preferences.neverTouch`) can add to it and never subtract.
   A protected process classifies as `.protected` and can never be selected, planned or signalled.
6. **Re-verify right before every signal.** Immediately before each `kill`, `Signal.swift` re-reads that pid and
   `StopPlanner.verify` must say `.ok`: same pid, **same start time** (seconds and microseconds), **same executable
   path**, same uid, same signature id, and still classified Ghost (for a Ghost approval) or Ghost/Maybe (for a
   confirmed single Maybe). Otherwise nothing is sent and the target is logged `changedSinceScan`. There is no
   suspension point (`await`) between verification and the `kill` call. (pid-reuse defence; the remaining race is a
   few microseconds and is accepted and documented.)
7. **Polite first, leaf-first.** SIGTERM first, deepest processes first (children before parents), wait up to 5 s per
   wave (returning early when everything exited), then report survivors. SIGKILL is sent only by a `.force` plan that
   was built from a stop outcome's survivors after an explicit per-group "Force stop" click and its own confirmation.
   Never automatic, never in a loop, never in a bulk action.
8. **The log.** Every target of every stop is appended to the activity log (JSONL, append-only, file mode 0600 in
   `~/Library/Application Support/Overstay/`, directory 0700), including skipped, blocked and failed ones. A `signalled` line is written before each signal is sent (write-ahead), then the outcome. A line holds
   the signature id, executable basename, pid, project **folder name**, footprint, result, errno and the "why" line.
   **No argv, no environment, no full paths.**
9. **Selection.** Default selection is Ghosts only. Maybe-tier items are never part of a bulk action; each is stopped
   one at a time after its own confirmation, and anything that started under 24 h ago (`Preferences.confirmYoungerThanHours`)
   needs an extra explicit tick.
10. **Never read file contents.** Project detection is `stat` only. The only file Overstay reads is its own activity log.
11. **argv and env are secrets.** argv is read in memory, scrubbed (`Scrub.argv`: secret-looking values replaced,
    capped length and count) before it enters any model, and shown only on the user's own screen. Environment values are
    never stored, logged, copied or put in the model: only the names of allow-listed keys (`EnvMarkers.allowed`) are
    kept. Nothing prints or logs argv/env (no `print`, `NSLog`, `os_log`).
12. **No network** (§1). No `URLSession`, Network framework, sockets, web views, `AsyncImage`.
13. **No undo.** A stopped process cannot be un-stopped. The UI says so plainly before the first stop and links to the
    log. Never write "undo", "restore" or "safe to stop". Also never promise freed memory: "held", not "freed".
14. **Fail closed.** If the activity log cannot be opened for appending, the stop does not start (every target is
    `blocked`, detail "Activity log is not writable"). If libproc cannot read a pid at verification time, it is
    `alreadyGone` or `changedSinceScan`, never signalled. If a write-ahead line cannot be written, that signal is not sent and nothing more is signalled.
15. **Naming/attribution rule** (§1) and no personal home paths in tracked files.

### 4.2 Classifier (`Classify/Classifier.swift`, `Why.swift`)

```swift
public enum Classifier {
    /// Pure. One process, judged in the context of the whole scan.
    public static func classify(_ p: ProcessSnapshot, in world: World, prefs: Preferences, now: Date) -> ClassifiedProcess
    /// Every same-uid process, in pid order; callers keep the listed ones.
    public static func classifyAll(_ world: World, prefs: Preferences, now: Date) -> [ClassifiedProcess]
    /// A Maybe younger than `prefs.confirmYoungerThanHours` needs an extra tick before a single stop.
    public static func requiresYoungConfirmation(_ c: ClassifiedProcess, prefs: Preferences, now: Date) -> Bool
}

public enum Why {
    /// One plain sentence group for the detail row, e.g.
    /// "Parent is gone. Looks like an MCP server. No live session in foo."  (Ghost)
    /// "Parent is gone. Looks like an MCP server. A live session is using foo, so it may still be needed."  (Maybe)
    /// "Parent is gone. Looks like an MCP server. Started 4 minutes ago, under the 10 minute gate."  (Maybe)
    /// "Parent is gone. Matches a generic pattern, so Overstay is not sure."  (Maybe)
    /// "Protected: inside an app bundle."  (protected)
    public static func line(_ e: SignalEvidence, tier: Classification, signatureTitle: String?, project: String?) -> String
}
```

Order of decisions (first match wins), with `evidence` filled as it goes:

1. `Protected.reason(for:in:prefs:)` non-nil → `.protected`, `evidence.protectedReason = reason`.
2. `uid != world.uid` or zombie or empty argv and empty path → `.ignored`.
3. `Signatures.match(p)` → first matching `Signature` in table order (specific entries before generic); none → `.ignored`.
   A match whose `kind == .agentRoot` → `.protected` ("agent session").
4. `orphaned = (p.ppid == 1)` and `world` knows no live pid `ppid` otherwise. Not orphaned → `.ignored` (it belongs to a
   running parent). Orphaned alone means nothing; it counts only together with step 3.
5. `evidence.liveSessionPids = world.liveSessionPids(for: p)`: running agent-root processes (same uid) whose
   `projectRoot` equals `p.projectRoot`, or, when either has no projectRoot, whose `cwd` equals `p.cwd`. IDE hosts
   count only when their own cwd/projectRoot matches (an IDE with an unknown workspace does not make everything live).
6. `ageGateMet = p.age(at: now) >= prefs.ageGateSeconds` (default 10 minutes).
7. `p.stdin == .writerAlive` also demotes to Maybe (someone still holds the other end). `.writerGone` never promotes.
8. Tier: `.ghost` iff signature `.specific` and no live session and age gate met and stdin is not `.writerAlive`;
   otherwise `.maybe`.
9. `agent`: the signature's agent; if `.unattributed`, `EnvMarkers.agent(for:)` of the first env marker; else `.unattributed`.
10. `why = Why.line(...)`.

### 5.5 `Signal.swift` (the only file with `kill(`)

```swift
enum Signaller {      // internal to OverstayMac
    /// Runs a plan. Never throws. Steps, exactly:
    /// 1. group targets into waves by `depth`, deepest first;
    /// 2. per wave: `world = Scan.world(ProcessScanner.scan(now:))` (fresh), then for each target synchronously:
    ///    `fresh = ProcessScanner.snapshot(pid:)`; `StopPlanner.verify(...)`; `.gone` -> alreadyGone, `.changed` ->
    ///    changedSinceScan, `.blocked` -> blocked (nothing sent); `.ok` -> hard guards (`pid > 1`, `pid != getpid()`,
    ///    `pid != getppid()`) then `send` with NO `await` between verify and send;
    /// 3. after the wave, poll every 100 ms up to `plan.graceSeconds`: a target counts as exited when
    ///    `ProcessScanner.snapshot(pid:)` is nil or its identity differs; exited -> stopped (or forceStopped for
    ///    `.force`), still there -> survived;
    /// 4. every TargetOutcome goes to `progress` and to the activity log as it is produced.
    static func run(_ plan: StopPlan, prefs: Preferences, now: @Sendable () -> Date,
                    progress: @Sendable (TargetOutcome) -> Void) async -> StopOutcome

    /// The ONLY call to kill(2) in the code base. SIGTERM for `.term`, SIGKILL for `.kill`; no other signal number is
    /// expressible. Returns 0 or errno (ESRCH -> alreadyGone, EPERM -> refused, else failed).
    private static func send(_ signal: Kind, to pid: Int32) -> Int32
    private enum Kind { case term, kill }
}
```

`.force` plans use `Kind.kill`, `StopPlan.mode == .force` only; `.terminate` plans can never reach `Kind.kill`.
`send` starts with `precondition(pid > 1)`.
